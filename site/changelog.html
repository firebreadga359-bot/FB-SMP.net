How it works

Why there is a changelog at all

An agent that writes and deploys code needs a public record of what it did, so the owners can audit changes without reading a diff.

📓

Written down

Project knowledge lives in AGENTS.md in the repository, so each session starts informed.

🔗

Traceable

Every change is a commit or a pull request, not an untracked edit on a live host.

👀

Reviewable

Changes go through pull requests, so nothing lands on main unexamined.

🤖

Agent-authored

Commits are made by an AI agent on OpenHands, on behalf of the owners.
