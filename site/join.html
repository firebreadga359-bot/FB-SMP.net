Java Edition

Desktop, macOS & Linux

Works on vanilla Minecraft. Copy the address below, then follow the steps.

cairo-paste.tun.ply.gg:25565
  1. Copy the addressUse the button above — the host and port are separate fields in Minecraft, so you may need each part.
  2. Open Multiplayer → Add ServerGive it any name. Paste cairo-paste.tun.ply.gg as the server address and 25565 as the port if it asks for one.
  3. Join and say helloYou land with a starter kit. Type /help to see the commands that matter.
Version note: the server targets the current release. If your client is far behind, update it — cross-version play is supported within a small window, not across years.

Bedrock Edition

Phone, console & Windows

Geyser translates Bedrock clients, so the same world is reachable from any Bedrock device. Copy the address first.

fried-toilette.tun.ply.gg:37298
  1. Copy the address and portBedrock asks for the server and the port in two separate boxes: host fried-toilette.tun.ply.gg, port 37298.
  2. Open Play → Servers → Add ServerPaste the host and port into the two fields, then save.
  3. Join the serverCrossplay is enabled, so no extra settings are needed.
On console: add the server under Servers in the Play menu. If your console hides the option, connect from a phone or Windows once and it will appear.

If it won't connect

Troubleshooting

"Can't connect to server"
Check the address for typos first, then confirm the status cards above say Online. If Java is up but you still can't connect, your client version is the most likely cause — update Minecraft.
Bedrock says "Unable to connect to world"
Make sure the port is 37298 and not left blank. On some consoles you must first add the server from a phone or the Windows Bedrock app before the entry appears.
I get kicked right after joining
This is usually a version mismatch or a whitelist check. If you requested an invite, confirm you received a reply before retrying.
High ping or lag
The world is hosted on shared infrastructure and reached through a tunnel, so latency varies by region. Try at a different time of day and avoid heavy chunk-loading right after joining.
